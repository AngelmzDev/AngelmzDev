## Sobre mí

<p data-importer="text" align="left">Soy Ángel Menendez, desarrollador de software en España. Creo herramientas para simplificar tareas y mejorar el trabajo diario, con interés en las aplicaciones de escritorio y la automatización.</p>

Mis proyectos parten de necesidades concretas: mantener una ventana visible mientras trabajo, reducir tareas repetitivas y organizar flujos de creación de contenido. Utilizo IA como apoyo para crear prototipos, explorar soluciones y documentar el proceso.

## Proyectos destacados

| Proyecto | Qué hace | Explorar |
| :--- | :--- | :--- |
| **Awtop** | Utilidad de escritorio en **C# / .NET para Windows**. Permite elegir una ventana, mantenerla en primer plano y retirar la prioridad con un clic. | [Código y uso](https://github.com/AngelmzDev/Awtop) |
| **Automatización de vídeos** | Herramienta propia que prepara un flujo de generación de contenido a partir de un título y una duración. | [Descripción en el portfolio](https://angelmzdev.github.io/#projects) |
| **Extensión para Meta.ai** | Automatiza el envío de prompts preparados para reducir el trabajo repetitivo. | [Descripción en el portfolio](https://angelmzdev.github.io/#projects) |
| **Wazuh SOC Lab** | Documentación de la instalación de un laboratorio **SIEM/XDR con Wazuh sobre Ubuntu Server**, con una utilidad de administración. | [Repositorio y documentación](https://github.com/AngelmzDev/Wazuh-SOC-lab) |
